# 10K Websites — External Reference Boundary

This directory preserves the 10K Websites methodology as research material.

It is NOT an active governing UIUX_Skills skill.

The methodology contributes useful lessons in:

- design before implementation
- explicit design packages
- cinematic direction
- scroll and motion engineering
- mobile/static fallback thinking
- adversarial self-testing
- accessibility
- visual quality review
- asset inspection
- real deployment verification
- structured troubleshooting

Its mandatory pipeline does NOT govern UIUX_Skills.

Do not automatically impose:

- plain HTML-only architecture
- single index.html applications
- vanilla JavaScript-only architecture
- Higgsfield dependency
- Hostinger dependency
- cinematic hero video
- static-site deployment
- its fixed phase sequence

The Dynamic Web Builder and the target repository determine application
architecture.

External methodology supplies lessons, not authority.
