# Design Reference Library

Reusable visual evidence for high-end application development.

Folders:

- mobile — mobile application references
- applications — complete product/interface references
- interaction — specific interaction patterns
- current-products — screenshots of products currently being improved

References are evidence, not templates.

Extract principles such as hierarchy, density, action placement, navigation,
interaction behavior, disclosure depth, state handling, and mobile rhythm.

Do not copy another product's branding or complete composition.
