# Product Engineering Troubleshooting Memory

This library stores reusable problems proven across applications.

Do not put speculative diagnoses here.

Use this format.

---

## Symptom

What was visibly wrong?

## Context

What type of application/surface/environment?

## Verified Cause

What evidence established the actual cause?

## Fix

What smallest reliable change corrected it?

## Verification

How was the correction proven?

## Reuse Boundary

When should this fix be considered again?

When should it NOT be generalized?

---

Project-specific defects remain in the project's own repository.

A reusable lesson graduates here only when it represents engineering knowledge
worth preserving beyond one project.
